Bottom line

Confirmed on 600 new episodes: the 90% barrier beats the policy and UNISafe.

Pre-registered confirmatory run on 600 never-used episodes, 2× noise, 96 s limit. The 90% barrier passes all three tests: topples 117 → 50 with 32 more successes than the policy alone, free at the real noise, and fewer topples and more successes than UNISafe (labelled). It repeats the first head-to-head (118 → 44), so the paper can now claim the 90% setting. The 1.6 s value at the 80% barrier also passes, not different from 90% except for more time-outs.

    Method: label-free gated edit

    The filter never sees a topple label. It judges a move only by imagining it many times, slightly off, in a learned world model. If the imagined move cannot be undone, the filter nudges the policy's move by at most 1 cm toward states a learned value calls steady. The value is trained only on how much the imagined futures scatter.

    Imagination at runtime, two depths: the gate rolls out 64 noisy futures over the whole look-ahead once per move (0.8 s). While the gate is open, the edit rolls out 8 noisy futures one step ahead every 0.2 s and scores them with the value V. V stands in for the long rollout: it was trained offline on how far 64 imagined futures scatter.

    Topple labels are used only to grade results. On dev episodes (100, 2× noise): 27 → 6 topples vs the policy alone, successes 64 → 77. The method is being updated to an always-on edit with an irreversibility value (see latest results); this section will be redrawn when it is frozen.

    How to read the filter videos
    • Four controllers, same start, same noise. Dashed white is where the policy wanted to move (○ marks its end). Solid is what was actually executed.
    • An orange frame means the filter is changing the policy's action right now, and the badge says by how much. No orange means the policy's action runs untouched.
    • Green / magenta patch (learned-value filters, only while the filter is on): the filter's own check re-run for targets up to 2 cm around the policy's. Green = its value accepts the target, magenta = it rejects it. The white square is the 1 cm edit limit. It is a slice of the latent safe set, not the set itself, and uses fresh noise draws; it agrees with the filter's real decision on the policy's own action on 82–88% of steps for the label-free arms and 99% for the labelled filter (all 9 episodes).
    • The bars under each view mark every 0.1 s step the filter changed, with height = how far it moved the target (full scale 15 mm).
